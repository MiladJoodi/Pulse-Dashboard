# Pulse

A modern admin dashboard built with React and Tailwind CSS. Clean, responsive, and ready to use.

## Tech Stack

- **React 19** — UI library
- **TypeScript** — type safety
- **Vite 6** — fast dev server and bundler
- **Tailwind CSS 4** — utility-first styling
- **Motion** — animations
- **Recharts** — data charts
- **Lucide React** — icons


## Getting Started

```bash
npm install
npm run dev
```

Opens at `http://localhost:3000`.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Type-check with TypeScript |

## Login

Use any email and password to log in. No database required — it stores data in memory.

## Pages

- **Overview** — stats, charts, recent activity
- **Users** — manage users
- **Tasks** — kanban board with drag & drop
- **Analytics** — charts and metrics
- **Messages** — broadcast system
- **Pricing** — plan comparison
- **Settings** — profile, security, preferences

Press `Ctrl+K` to open the command palette and quickly navigate anywhere.
